# PAT-ECG

The components required for the build are as follows:
Teensy 4.0 microprocessor board with USB lead.
A box to house the Teensy board.
13-bit optical Gray code encoder with lead.
25-way D-type female connector.
25-way male connector and casing.
A knob to attach to the output shaft of the encoder.
Computer speakers with built in amplifier.
